# check/expr/

The module `Check.Expr` (claude/modules-style-pass.md): Expressions (Type System ch.

- `mod.prism`: the main file: the header; inference, names, literals.
- `calls.prism`: a section; calls, lambdas.
- `lets.prism`: a section; expression blocks and `let`, function clauses under a signature, templates.
- `lifting.prism`: a section; `match` and `if` as lifting.
- `operators.prism`: a section; arrays, maps, operators, field access and indexing.
- `patterns.prism`: a section; patterns.

Written by Claude on the claude-self-hosting branch; subject to change.
