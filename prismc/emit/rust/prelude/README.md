# emit/rust/prelude/

The module `Emit.Rust.Prelude` (claude/modules-style-pass.md): The prelude of every compiled program (Semantics Appendix B; prelude/prelude.prism): its builtins and the functions it writes in Prism, as Rust over `prism_rtl`, emitted as `src/prelude.rs` word for word.

- `mod.prism`: the main file: the header.

Written by Claude on the claude-self-hosting branch; subject to change.
