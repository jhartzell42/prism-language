# prismc/emit/rust/templates/

The module `Emit.Rust.Templates` (claude/modules-style-pass.md): The Rust template set (Templates ch. 2, code templates; Compiler ch. 4, "Templates, and two template sets"): every item of the emitted Rust as a function-form template with doubled braces.

- `mod.prism`: `Emit.Rust.Templates` itself: Comments; Files.
- `items.prism`: `Emit.Rust.Templates.Items`, a child module: Types; Functions and jobs; Nodes; Expressions and statements that take several lines.

Written by Claude on the claude-self-hosting branch; subject to change.
