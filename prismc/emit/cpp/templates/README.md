# prismc/emit/cpp/templates/

The module `Emit.Cpp.Templates` (claude/modules-style-pass.md): The C++ template set (Templates ch. 2, code templates; Compiler ch. 4, "Templates, and two template sets"): every item of the emitted C++ as a function-form template with doubled braces.

- `mod.prism`: `Emit.Cpp.Templates` itself: Files.
- `items.prism`: `Emit.Cpp.Templates.Items`, a child module: Types; Functions, jobs, traits; Nodes and programs; Expressions and statements that take several lines.

Written by Claude on the claude-self-hosting branch; subject to change.
