# emit/cpp/prelude/

The module `Emit.Cpp.Prelude` (claude/modules-style-pass.md): The prelude of every program compiled to C++ (Semantics Appendix B; prelude/prelude.prism): its builtins and the functions it writes in Prism, as C++ over `prism_rtl`, emitted as `src/prelude.hpp` word for word: the C++ form of templates/prelude.prism, function for function, under the same names (a C++ keyword with `_` after it: `or_`, `int_`).

- `mod.prism`: the main file: the header.

Written by Claude on the claude-self-hosting branch; subject to change.
