# syntax/parser/

The module `Syntax.Parser` (docs/modules-style-pass.md): The parser: tokens to the tree of ast.prism (Semantics ch.

- `mod.prism`: the main file: the header; the cursor, names.
- `blocks.prism`: a section; blocks and statements.
- `decls.prism`: a section; the top-level forms.
- `expr.prism`: a section; expressions.
- `test_language.prism`: a section; the test language.
- `tests.prism`: a test module.
- `types.prism`: a section; types, rows and bounds, patterns.
- `tests.expected`: the transcript of `tests.prism` under the Test World.

Written by Claude on the claude-self-hosting branch; subject to change.
