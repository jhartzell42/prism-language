# cpp-trait-across-modules

The conformance program `cpp-trait-across-modules`, a tree: `app.prism` (the root, whose
header says what it pins), `aloud/` (`Aloud`, a trait with a default method and a generic
function over it), `zoo/` (`Zoo`, a type and its impl of the trait), `tests.prism` and its
`tests.expected`.

Written by Claude on the claude-self-hosting branch; subject to change.
