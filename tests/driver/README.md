# tests/driver/

The `prism` driver and prismc's own options, through `run.sh`: the World `prism run`
picks for a root (`cli-root.prism`, a loose file; `gui-tree/`, a tree whose root emits
`Gui.*` and has a child module `Title`), options refused, an absolute `-o` (the runtime
at `PRISM_ROOT`, or refused naming `--runtime`), and chess compiled to C++ under the
canvas World. This README stands for `gui-tree/` too.

Written by Claude on the claude-self-hosting branch; subject to change.
